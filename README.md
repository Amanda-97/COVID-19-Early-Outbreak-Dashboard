# COVID-19 Early Outbreak Dashboard

## Project Overview

This project is a web-based dashboard that visualises the early spread of COVID-19 between February and March 2020.

The dashboard focuses on five countries: China, Italy, South Korea, the United States and South Africa.

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
- Visual Studio Code
- GitHub

## Current Progress

- Created the dashboard structure.
- Added styling and layout.
- Loaded the COVID-19 JSON dataset successfully.
- Added a country selector for the five countries.

## Upcoming Features

- COVID-19 trend line chart.
- Daily new cases bar chart.
- Confirmed cases, deaths, recoveries and active cases.
- Country and date filtering.
- Testing and documentation.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Start the project using the Live Server extension.
4. Open the dashboard in your browser.

## Data Source

Johns Hopkins University Center for Systems Science and Engineering (CSSE) COVID-19 Data Repository.

## Project Period

February to March 2020.
